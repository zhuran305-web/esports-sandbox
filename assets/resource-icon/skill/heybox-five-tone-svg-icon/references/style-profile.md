# 五色内部图标风格画像

## 样本基线

本画像来自用户提供的 54 个内部 SVG 样本。所有样本都是 `154×154` 画布。渲染后的非透明外接框中位数约为 `124×124`，等效占位边长 `sqrt(width×height)` 中位数约为 `122 px`；四边留白中位数为左 15、上 14、右 14.5、下 16 px。大多数图标的宽高落在 112–136 px，带横向附件或角标的少数图标可扩展到约 144 px。

这是一套居中的小尺寸功能图标，不是插画。54 个文件中有 1 个内嵌位图样本，因此几何和像素统计使用其余 53 个真矢量文件。样本语言是粗而温和的深色边框、下移硬投影、低复杂度主体、上亮下暗的硬边色面，以及一个承担语义的强调部件；不是三色等面积斜切。

## 固定五色系统

以用户确认的正式色板为唯一标准。“亮”与“白”是两个独立层级，不能合并；`#8D8D9E` 不属于本五色板：

| 色槽 class | 默认值 | 用途 |
|---|---:|---|
| `icon-outline` | `#593408` | 主外轮廓、关键内线、向下错位的实色硬投影 |
| `icon-dark` | `#EC7424` | 暗：主体下侧或背向面的硬边暗面，不做柔化 |
| `icon-gray` | `#FFA53D` | 灰：主体占比最大的中间基面 |
| `icon-light` | `#FFBF75` | 亮：主体上侧受光面，面积小于灰基面 |
| `icon-white` | `#FFFFFF` | 白：最亮表面、必要脸部留白或独立局部高光 |

53 个矢量样本的可见像素统计显示：描边与硬投影通常占比较高；灰色中间基面是最大主体面；暗面重心明显靠下；`#FFBF75` 亮面通常约占一成以内；纯白局部高光通常最小。比例只用于判断层级，不是每张图必须机械命中的配额。

默认相对明度必须严格满足：`icon-outline < icon-dark < icon-gray < icon-light < icon-white`。换肤可以改变色相，但五级明度顺序不能颠倒。

五个值必须在唯一的 `<style>` 节点里集中定义，每个 class 只写一次 `color:#RRGGBB`，作为 Token 清单。为了兼容导入时会丢弃 CSS 的设计软件，每个可见几何元素还必须写显式十六进制颜色，并用 `data-fill-token`、`data-stroke-token` 分别记录填充和描边属于哪个 Token。例如：`data-fill-token="icon-gray" fill="#FFA53D" data-stroke-token="icon-outline" stroke="#593408"`。同一 Token 在所有元素上的显式色值必须一致；换色脚本同时更新 Token 清单与元素颜色。

禁止用 `currentColor`、CSS 自定义属性或祖先继承承载交付颜色。浏览器预览能解析这些形式，不代表 Figma 等编辑软件拖入后仍会保留；显式 `fill` / `stroke` 才是交付基线。

## 主体提取与简化

- 先回答“这个图标在 24 px 下代表什么名词或动作”。不能一句话说清的元素通常应被删减。
- 保留一个主轮廓和最多两个身份特征，例如票券的缺口、手柄的摇杆、日历的装订环。装饰性纹理、真实材质、细小阴影和背景框不属于主体。
- 输入中的标题、标签、角标、品牌字样默认删除。只有在移除后会改变语义时才保留，并先转成简化轮廓；不要依赖字体或 `<text>`。
- 多物件场景改为“主物件 + 必要附件”或轻微叠放，不做等权重拼贴。由明暗层级突出决定主题的附件，其他对象继续使用灰面和上下明暗面。
- 曲线与圆角应略夸张，所有非语义必需的尖角都要软化；优先用少量连续贝塞尔曲线描述轮廓，禁止以短折线拼接曲面。内部空隙要足够大，缩到 24 px 后不能糊成一块。
- 不为了“更丰富”添加亮点、横条、星芒、圆点、重复符号或纹样。白色高光只能贴合上左侧轮廓或强调部件表面；一个元素只有在表达形体、材质或连接关系时才保留。
- 默认先问能否用一个连续块面或负形表达；能用面表达时，不再补平行内描线、纹理短线或速度刻痕。删除线后也不添加无归属的浮动色块，所有内部块面都要被明确物件的轮廓裁切。
- 文字主体不使用额外承托外形，字母或汉字自身就是块面。保留原字标最有辨识度的宽窄、倾斜、开口和字腔，将文字转为闭合路径后压紧字距，使相邻字接近或轻微咬合，形成一组紧凑字标。每个字形内部共享一致的上亮、中灰、下暗分面，轮廓仍完整可读，整组只生成一套下移硬投影。禁止云形底板、像素格、逐笔小矩形、残缺字腔或为了连通而把字压到无法辨认。
- 文字批量输出时先归一化实际字重。以 154 px 渲染结果测量主要竖干或横干：拉丁字面主干约 `9–14 px`，低于 `8 px` 的细字必须换成更粗骨架或对闭合路径外扩；高密度汉字的核心笔画约 `5.5–8 px`。同组主干粗细差优先不超过约 `25%`。路径外扩后要人工重开字腔和字符间隙，保证内孔与开口在 24 px 下仍可见。外描边继续固定 `4.2 px`，不得通过加粗描边代替字面加粗。

### 复杂主体的识别锚点

复杂人物、机械体、特效物件或多对象画面先做“完整主体还是局部锚点”的选择，不要默认把全部内容一起抽象。分别列出三个层级的候选：完整主体、位于主体内部的核心图案、画面或名称中明确出现的次级语义物件。选择能够以最少形状保留最强语义的层级。

只有同时满足以下条件时才重绘完整主体：外轮廓本身有辨识度；用 1–2 个身份特征即可与同类区分；删除纹理和小零件后仍与关键词一致；缩到 24 px 后不依赖内部碎线才能识别。若人物姿态、机械零件或特效层叠必须大量保留才能成立，完整主体不是合格候选，应转而寻找局部锚点。

局部锚点按以下顺序判断：

1. **语义直接**：它必须在原图中清楚可见，或被名称、用户描述明确点出；移除其余内容后仍能关联原主题。禁止凭空补一个常见符号替代原图。
2. **形状独立**：它应具有连续外轮廓、明确负形或稳定的几何节奏，能脱离原场景成为一个完整图标，而不是依附在其他物体上的半截纹理。
3. **小尺寸强**：它在 24 px 下比完整主体更容易辨认，并能用一个主轮廓和最多两个关键结构表达；不能靠增加装饰线说明含义。
4. **五色可重绘**：它能自然容纳灰基面、上下明暗面、局部白色受光面与完整描边，不需要渐变、透明特效、细密纹理或大量穿插线。

多个局部都满足时，优先选择与名称关键词最直接的，其次选择轮廓差异最大、重绘最稳定的；不要把两个弱候选拼在一起。选定锚点后，画面应只留下该锚点及确有必要的一个从属结构，原主体的肢体、外壳、发丝、特效环和其他残片全部删除。局部若来自人物配件或植物，不再套用人物头部和表情模板。

典型判例：中心眼形本身是最强符号时，只重绘眼形及其必要眼眶，不保留外围断裂飘带；人物造型压缩后失真，而百合在画面或名称中是明确身份特征时，只重绘一朵百合；“轨道机械核心”中机械细节过密时，以一组清楚的轨道关系作为主体，中心核心只作为帮助理解轨道的从属块面。这里的眼、百合和轨道只是选择层级的示例，不是固定模板。

最终在 24 px 下进行二选一比较：若局部版本比完整版本更快读出关键词且没有变成同类通用图标，采用局部版本；若局部过于泛化、脱离名称就无法识别，退回完整主体并继续删减，而不是增加无关装饰补偿。

保留完整动物或物件时，再做一次“类别轮廓”检查：先遮住颜色和内部细节，只看外轮廓与最大附件是否仍能认出类别。决定类别的嘴、耳、角、翼、鳍、尾、轮组或工具头必须保持足够面积和源图中的相对强调程度，不能为了轮廓圆润而全部收成通用圆体。例如鸭子至少应让大鸭嘴、翼和脚中的两个成为第一眼可见结构；若只剩蛋形身体和小侧块，应判定为鸭形丢失并重画，而不是补眼睛或花纹挽救。

## 构图和线条

- 画布与视觉中心：固定为 `154×154`。以包含描边、附件和硬投影的完整非透明像素外接框为准，54 个样本的中心中位数为 `(77, 76.5)`；生成稿横纵中心偏差各不超过 3 px。不要只让主路径居中而把附件或硬投影排除在计算外。
- 同组尺寸一致性：优先与用户提供的同组 SVG 比较渲染外接框；有多张时选 3–5 张宽高比和结构最接近的参考并取中位数。用 `sqrt(width×height)` 比较整体占位，生成稿与参考中位数相差不超过 8 px；无参考时以 `122 px` 为目标。这样允许横长、竖长主体保持自身比例，同时避免明显偏小或偏大。
- 常规安全区：优先让可见外接框落在 `x=12–142`、`y=10–140`；典型四边留白 12–18 px。圆形、旗帜和带角标结构允许按光学平衡微调。
- 257 个可见描边元素中，187 个使用 4.2 px，说明 4.2 px 是不可动摇的主描边。为避免小尺寸出现纤细装饰线，本 Skill 的交付稿把 4.2 px 同时作为可见结构线下限；开放路径若本身代表尾巴、手柄等实体部件，可以用更粗描边。所有开放路径使用 `stroke-linecap="round"`，所有转折使用 `stroke-linejoin="round"`。
- 开放路径必须有完整的 A、B 两端：两端都接到轮廓、结构节点或另一条路径，或作为真实实体部件的可见圆端结束。遮挡线先画在后景，再由前景不透明块面覆盖并收口；禁止悬空、只连一端、无故断线或把后景线画到前景上。
- 细节总量以识别为准。通常 3–12 个主要矢量形状即可；复杂主题也应优先合并路径，避免把原始 SVG 的碎片结构原样搬过来。复杂人物和角色不能只用路径数量判断：以 154 px 渲染后的视觉边界密度为准，默认控制在 `25.5–38.5`，具体计算见 `character-expression-and-complexity.md` 和 `scripts/svg-icon-tool.mjs complexity`。
- 轮廓必须闭合、没有自交和不必要的重叠边。需要挖空时优先使用 `fill-rule="evenodd"`，谨慎使用蒙版；所有 `id` 必须唯一。
- 描边和填充必须分别绑定 Token：闭合主体可同时使用 `data-fill-token="icon-gray"` 与 `data-stroke-token="icon-outline"`，不能因为填充使用 `icon-gray` 就让描边也继承灰色。同一物件的无描边 `dark`/`light`/`white` 色面必须裁切在该物件轮廓内，并在色面之后重画本物件轮廓；每个可见色块的边缘要么由自己的描边包住，要么被明确位于前景的不透明物件遮住，不能留下无归属的裸露色块。
- 遮挡不是靠补线表现，而是靠绘制顺序实现。后景物件先完成填色、内部色面与自身轮廓，前景物件再以不透明填色覆盖交界；每个物件的轮廓都留在它自己的语义分组内。相邻文字需要咬合时也按阅读顺序逐字完成，让前字或后字的遮挡关系保持一致；不要用一块外轮廓包住全部文字，也禁止先绘制全部填充、再把所有轮廓集中到最后一层统一描绘。

## 硬投影与色面结构

1. 从完整主体轮廓生成向下错位的实色厚度，使用 `icon-outline` 同色填充与至少 4.2 px 圆角描边。样本重复路径的错位量主要落在 4.2–5.6 px，中位数为 5.6 px；默认使用 `translate(0 5.6)`。所有带独立外轮廓的实体附件也复制同方向硬投影，再由原位前景覆盖交界。轨道、圆环、框体等环形实体先用 `fill-rule="evenodd"` 或布尔差集做成有真实面积的闭合带，闭合带的内外边缘统一由 4.2 px 描边包裹，并为整条带生成硬投影；禁止在粗描边后面或里面再叠一条细圆环充当色面。下移轮廓与原轮廓在左右底角必须圆滑并合；若直接复制会露出台阶、尖刺或矩形凸耳，改为圆角并集或重绘一条与两侧切线顺接的底沿。
2. 在原位置绘制 `icon-gray` 主体并加 4.2 px `icon-outline` 描边。前景会盖住硬投影，只留下底边和局部下侧厚度；不要使用模糊、透明度、滤镜或独立椭圆地面投影。
3. `icon-dark` 用矩形裁切、蒙版或简洁闭合路径落在主体下侧，通常约占可见面积 7%–14%。所有内部色面必须被本物件轮廓裁切，并在其后收口本物件描边；边界水平或顺着明确的结构线，不能切成随机斜块，也不能覆盖或越过外轮廓。
4. `icon-light` 形成主体上侧受光面，面积小于灰基面；它必须与 `icon-white` 保持可见层级差，不能以白色代替。
5. `icon-white` 形成最小、最亮的局部受光面，或用于必要的脸部留白。局部高光使用单一闭合填充形，紧贴上左侧表面并顺应形体；不再使用细白线。眼白不能替代物体表面的高光。

面性检查关注前后层级：硬投影在最下且与底部轮廓圆滑连接，后景物件先完成，灰色主体基面居中，前景部件以填色遮住后景交界，暗面靠下，亮面靠上，白色局部受光面最小且最亮。后景线条穿入前景、内部色面浮在或盖住描边、靠补丁色块遮线、硬投影底角出现台阶尖刺、四周均匀描边式“假投影”、随机拼接色块或悬浮高光，均为失败。

## 合格判断

合格图标应同时满足：24 px 可识别主体；154 px 看不到锯齿曲面、明显锐角、粗糙拼接或错误穿插；主描边和最细结构线均不小于 4.2 px；下沿能读到约 5.6 px 的硬投影；暗、灰、亮、白层级清楚；五个色槽可一次换肤；没有第六色、渐变、模糊、透明叠色、位图或外链。

常见失败包括：只给原稿换色、主体占比过小、贴边、草稿笔触、柔化投影、四周等宽假投影、渐变拟物、等面积斜切、把亮与白合并、只有眼白却没有表面高光、保留长文字、把背景误当主体，以及附件比主体更抢眼。
